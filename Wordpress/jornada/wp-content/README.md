## ✨ O que tem aqui

- `themes/`
  - inclui o **Astra** e temas padrão (`twentytwenty*`)
- `plugins/`
  - inclui plugins como **Elementor** e **Akismet**
- `uploads/`
  - mídias enviadas (imagens etc.)
- `languages/`
  - arquivos de idioma

---

## 🧭 Dica de estudo

Se o objetivo é aprender desenvolvimento WordPress:
- foque em **themes** e **plugins**
- evite editar o core (`wp-admin` / `wp-includes`) diretamente
