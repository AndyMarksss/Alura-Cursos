## ▶️ Rodar localmente (guia rápido)

1. suba um ambiente com PHP + MySQL (XAMPP/Laragon/LocalWP/Docker)
2. aponte o servidor para esta pasta (`jornada/`)
3. ajuste `wp-config.php` (conexão com o banco)
4. acesse no navegador e finalize
