## ✅ O que tem aqui

- `limpar()` zera lista e total
- `adicionar()`:
  - lê produto/quantidade
  - separa nome e preço com `split`
  - calcula subtotal e soma no total
  - atualiza HTML com `innerHTML` e `textContent`
