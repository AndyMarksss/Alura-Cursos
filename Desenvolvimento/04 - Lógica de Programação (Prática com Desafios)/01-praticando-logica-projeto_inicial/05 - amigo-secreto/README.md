## ✅ Regras do projeto

- não aceita nome vazio
- não aceita duplicado (`amigos.includes(...)`)
- exige mínimo de participantes para sortear
- embaralha (estilo Fisher–Yates) e monta pares na tela
- reinicia limpando lista e resultado

## ▶️ Rodando
Abra `index.html`.
