## 🧠 O que rola no `js/app.js` (pelo seu comentário)

- `comprar()` lê tipo + quantidade e encaminha pro setor
- funções por setor:
  - leem disponibilidade via `textContent`
  - validam quantidade
  - subtraem e atualizam na tela
  - alertam sucesso/erro
