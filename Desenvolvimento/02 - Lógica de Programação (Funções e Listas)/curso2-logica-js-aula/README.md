## 🧠 O que você praticou aqui (baseado nos seus comentários)

- `exibirTexto(tag, texto)` para centralizar atualização do HTML (`innerHTML`)
- controle de estado dos botões (`disabled`, `removeAttribute`)
- sorteio sem repetição com:
  - `listaDeNumerosSorteados`
  - `includes()`
  - “reset” quando a lista chega no limite
- limpeza do input + reinício do jogo
